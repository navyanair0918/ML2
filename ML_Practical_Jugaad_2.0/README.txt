ML PRACTICAL EXAM PACK

Files:
1. linear.py             - Simple Linear Regression
2. logistic.py           - Logistic Regression
3. bagging_boosting.py   - Decision Tree, Random Forest (Bagging), AdaBoost (Boosting)
4. multivariate.py      - Multivariate Linear Regression
5. svm.py                - Support Vector Machine

IMPORTANT:
- Each program uses 10 rows of data written directly in the Python file.
- No CSV files, Google Colab paths, internet downloads, or display() are required.
- The code follows the same general workflow and libraries used in your uploaded linear.py:
  imports, assumed/load data, train model, predict, evaluate, and plot.
- These are small illustrative datasets for a practical demonstration. With only 10 rows,
  test-set accuracy and R2 scores can vary and should not be treated as reliable real-world metrics.

Before the practical:
Install required packages in the lab computer if permitted:
    python -m pip install numpy matplotlib scipy scikit-learn

Run a file:
    python linear.py

If the IDE uses a Run button, open the required .py file and click Run.
Use Python 3 with the packages above installed.
